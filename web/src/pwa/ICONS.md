# App icons (web/public/icons)

These icons reuse the Gelabber speech-bubble mark from
`desktop/app/icons/icon.png`. The normal 192/512 px PNGs and the 180 px Apple
touch icon have an opaque `#17191a` background. The separate maskable icon
centres the mark at 320 px within a 512 px canvas so its important artwork
stays inside the maskable safe circle. No third-party artwork was added.
